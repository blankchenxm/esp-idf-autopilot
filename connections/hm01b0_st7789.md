MCU：ESP32-S3-WROOM-1 开发板。

外设包括：

1. HM01B0-MWA 摄像头。
2. ST7789 display。

ST7789 display 连接到 ESP32-S3-WROOM-1 的引脚如下：

```c
#define ST7789_PIN_SCL   35   // SPI CLK
#define ST7789_PIN_SDA   36   // SPI MOSI
#define ST7789_PIN_RES   37   // Reset
#define ST7789_PIN_DC    38   // Data/Command
#define ST7789_PIN_CS    39   // Chip Select
// BLK (背光) 直接接 3.3V 常亮
```

HM01B0-MWA 摄像头连接到 ESP32-S3-WROOM-1 的引脚如下：

```c
#define HM01B0_PIN_MCLK   5
#define HM01B0_PIN_PCLK   6
#define HM01B0_PIN_VSYNC  7
#define HM01B0_PIN_HSYNC  8
#define HM01B0_PIN_D0     9
#define HM01B0_PIN_D1     10
#define HM01B0_PIN_D2     11
#define HM01B0_PIN_D3     12
#define HM01B0_PIN_D4     13
#define HM01B0_PIN_D5     14
#define HM01B0_PIN_D6     15
#define HM01B0_PIN_D7     16
```

HM01B0-MWA 摄像头的 I2C 定义如下：

```c
#define HM01B0_I2C_SCL_IO    1
#define HM01B0_I2C_SDA_IO    2
```
